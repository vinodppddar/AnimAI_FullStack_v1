# AnimAI Frontend — Fixed

This is a dependency-free frontend replacement for the AnimAI_FullStack_v1 frontend.

## Run

1. Copy `index.html`, `style.css`, and `app.js` into:
   `AnimAI_FullStack_v1/frontend/`
2. Start backend:
   `uvicorn main:app --reload`
3. Start frontend:
   `python -m http.server 5500`
4. Open:
   `http://localhost:5500`

Do not open `index.html` with `file:///`.
